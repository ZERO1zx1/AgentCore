# Capability routing reference

Inspect artifacts by their operational role, not only extension: manifests/tests for code, routes and state for apps, schemas and lineage for data, page/slide rendering for documents, and metadata plus samples for media. Validate with the closest real check—tests/builds for code, contracts for services, rendering for documents, playback/probe for media, and invariant checks for data.

For cross-domain work, map producer → transformation → consumer and check each changed boundary. Inventory large inputs before loading them and preserve originals when conversion may be lossy. Deployment remains an explicit user-authorized action.
