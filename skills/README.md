# Skills (`skills/`)

Public operating policies and specialist routing. Each skill has its own
`SKILL.md`.

- `adaptive-omni-agent/` — general-purpose agent with bounded local memory.
- `code-engineer/` — code-focused work.
- `credit-safe-agent/` — lowest-cost, budget-safe work.
- `adaptive-local-memory/` — internal local-memory store used by adaptive-omni-agent (not installed as a separate public skill).

See the [AgentCore plugin](../plugin/README.md) for how these are distributed to individual agents.
